# employee-mobile (archiviato)

Questo progetto è stato archiviato perché la scelta di prodotto per i dipendenti
è le web app (cameriere, KDS bar, KDS cucina), non un'app nativa.

Le web app sono servite dal backend Express su `/waiter`, `/kds-bar`, `/kds-kitchen`
e sono accessibili da qualsiasi tablet/telefono via browser, senza installazione.

Non cancellare questa directory: contiene codice che potrebbe essere utile
come riferimento se in futuro si decidesse di tornare a un approccio nativo.
